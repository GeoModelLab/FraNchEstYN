## Datasets

- [`weather_indiana`](https://geomodellab.github.io/FraNchEstYN/reference/weather_indiana.md)
  : Daily weather for Indiana
- [`reference_indiana`](https://geomodellab.github.io/FraNchEstYN/reference/reference_indiana.md)
  : Indiana reference disease observations
- [`reference_egypt`](https://geomodellab.github.io/FraNchEstYN/reference/reference_egypt.md)
  : Reference dataset for Egypt, yellow rust severity and yield loss on
  seven wheat varieties (Sharkiya, 2013–2015)
- [`weather_egypt`](https://geomodellab.github.io/FraNchEstYN/reference/weather_egypt.md)
  : Daily weather dataset for Sharkiya, Egypt (2013–2015)
- [`reference_brazil`](https://geomodellab.github.io/FraNchEstYN/reference/reference_brazil.md)
  : Reference wheat data from Brazil (BRILHANTE cultivar, Sertaozinho
  site)
- [`reference_ethiopia`](https://geomodellab.github.io/FraNchEstYN/reference/reference_ethiopia.md)
  : Ethiopia reference disease observations
- [`weather_ethiopia`](https://geomodellab.github.io/FraNchEstYN/reference/weather_ethiopia.md)
  : Daily weather for Ethiopia fungicide trial sites
- [`management_indiana`](https://geomodellab.github.io/FraNchEstYN/reference/management_indiana.md)
  : Indiana management practices
- [`management_brazil`](https://geomodellab.github.io/FraNchEstYN/reference/management_brazil.md)
  : Management information for BRILHANTE wheat trials in Brazil
- [`management_ethiopia`](https://geomodellab.github.io/FraNchEstYN/reference/management_ethiopia.md)
  : Ethiopia management practices
- [`cropParameters_brazil`](https://geomodellab.github.io/FraNchEstYN/reference/cropParameters_brazil.md)
  : Default crop parameters for BRILHANTE wheat (Brazil)
